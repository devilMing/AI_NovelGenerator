# 章后事实与写作资料长度

## 引文位置校正

当模型引用的证据原句完全存在于固定正文修订中、且只有一个匹配位置时，允许确定性校正错误的字符下标；按 Python Unicode 码点计算。原候选和校正前后位置保留到检查点与正式事实批次的 `evidence_alignments`，随后重新独立审核。不会改动引文、事实值或正文，也不重置两次模型修订额度。引文缺失、重复且原位置不匹配、重叠多处匹配，仍走原来的严格校验与有界修订流程；对象身份和章前值的校验仍照常执行。

后续写作、章计划和补建已有章节的章后事实，读取每项已确认事实的完整当前值 `after`，并保留对象类型、稳定身份、字段、风险及来源章节、修订、正文散列。读取位置仍遵循章前边界，不读取未来章节的事实；过期正文修订仍要求先核对事实。

历史变更前值 `before` 和证据引文 `evidence` 用于审核追溯，不再在每次后续模型请求中重复携带。数据库中的原始事实、提取候选、审核报告和正文修订保持完整。来源指纹仍使用包含引文的完整事实，所以证据发生变化时，旧候选的来源校验仍能识别。

这属于模型资料的投影，不做数据库迁移，也不截取或概括事实值。作者要求和当前事实完整保留；若实际资料仍超过 20 万字符，继续明确报错，不静默截断。已保存在旧任务检查点中的候选与材料不回写；尚未完成的资料读取在继续后使用新投影，原任务的已完成进度保留。

回归检查包括：长引文导致原上下文超过上限时仍可补建已有正文事实；不调用正文生成、不改已有正文；完整值和来源保留；证据变化影响来源指纹；真正超长的事实值仍触发长度限制。

## 事实审核编号与重试

独立审核请求显式列出候选的零起始数组编号，并要求每项恰好返回一个决定。例如两项候选只能覆盖 `0, 1`；`1, 2`、漏项、重复、越界都不采用，不自动重编号或补造意见。审核格式错误转换为可读的 `CHAPTER_FACT_REVIEW_INVALID`，原始错误报告保留在任务检查点与日志中。

格式错误与审核引文错误共用最多两次自动重试额度。只重试当前独立审核，不重新提取事实或生成正文；已有合格的独立审核保留，高风险事实仍需两份合格审核。每次重试前持久化错误和次数，连续失败则暂停，之后手动继续仍复用正文和提取候选。网络、超时、鉴权等错误沿用各自处理，不占用这项格式修复额度。
