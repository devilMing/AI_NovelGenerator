# 更新日志

### 2026-10-23

#### 新增

- 新增从小说信息开始的一键写作：自动补齐所需资料与规划、生成并保存第一章，并可继续进入整卷自动写作。
- 新增章后事实闭环：正文保存后自动提取事实、独立审核并更新事实库，下一章会读取已经确认的最新事实。
- 新增后台运行日志与 Token 消耗统计，可查看写作步骤、耗时、重试记录、模型调用和用量汇总。
- 新增已完成章节导出，便于将当前作品正文整理为文本文件。

#### 优化

- 一键写作和逐卷写作支持自动保存、安全暂停、失败续跑及服务重启后恢复；已有正文会自动跳过，不会重复生成或覆盖。
- 完善模型与推理强度选择，并改进 ChatGPT 网页授权模式下的可用模型配置。
- 写作日志改为持久化时间线，保留重试、审核、事实提取与事实更新记录，同时隐藏凭据和内部推理内容。
- 长篇写作按已确认事实、章节修订和剧情边界逐章推进，降低人物状态、时间线、证据边界与资源数量发生漂移的风险。

#### 修复

- 修复暂停请求可能越过当前安全检查点、恢复后重复执行已完成准备步骤的问题。
- 修复事实审核引用非连续正文时任务无法自愈的问题；现在会保留正文和事实候选并自动重新审核。
- 修复保存响应丢失、人工修改正文或审核记录写入失败时可能重复生成或误覆盖的问题。
