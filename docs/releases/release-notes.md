# 更新日志

### 2026-10-25

#### 修复

- 章计划修订可从已实际读取且有冻结来源的角色中补填空视角；已有视角、名称、顺序、预算和其他引用仍受保护，修订后独立复核，解除缺失视角与保护规则相互阻塞的问题。

### 2026-10-24

#### 修复

- 章后事实的证据原句在固定正文中完全且唯一匹配时，自动校正错误字符位置并重新独立审核；保留原始候选与校正记录，不猜测重复引文、不改引文、不重置模型修订次数，旧失败任务可继续。
- 章后事实审核明确使用从 0 开始的候选编号；漏审、越界或格式错误时保留提取结果，最多自动重试审核两次并记录失败报告，不重新生成正文或事实候选，页面返回可读错误。
- 写作上下文只携带章后事实的完整当前值及来源标识，不再重复携带历史变更前值和长证据引文；证据原文仍完整保存在数据库并参与来源指纹检查，修复长篇逐卷写作补建事实时超过资料上限的问题。
- 一键首章写作的物品冲突直接使用完整候选、书初材料和引证修订，不再将长报告拼入限长的作者要求；未来才形成的物品可移出书初候选，并保留原候选、审核和修订检查点。
- 逐卷写作的自动修订扩展到未保存的篇章规划、场景规划和章计划；按原引证修正叙述并独立复核，最多两次，保留候选数量、顺序、名称、预算和实体引用，旧失败任务可直接继续。

### 2026-10-23

#### 新增

- 新建逐卷写作任务会先补齐缺少的卷详细剧情、卷资料、篇章规划、篇章剧情和场景，再逐章写作；已有内容保留，各准备步骤支持自动保存、暂停和续跑。
- 逐卷写作中的未保存正文出现有引证的一致性冲突时，自动修订当前候选并独立复核，最多修订两次；保留修订前后正文与审核记录，旧失败任务也可直接继续。
- 新增从小说信息开始的一键写作：自动补齐所需资料与规划、生成并保存第一章，并可继续进入整卷自动写作。
- 新增章后事实闭环：正文保存后自动提取事实、独立审核并更新事实库，下一章会读取已经确认的最新事实。
- 新增后台运行日志与 Token 消耗统计，可查看写作步骤、耗时、重试记录、模型调用和用量汇总。
- 新增已完成章节导出，便于将当前作品正文整理为文本文件。

#### 优化

- 一键写作和逐卷写作支持自动保存、安全暂停、失败续跑及服务重启后恢复；已有正文会自动跳过，不会重复生成或覆盖。
- 完善模型与推理强度选择，并改进 ChatGPT 网页授权模式下的可用模型配置。
- 写作日志改为持久化时间线，保留重试、审核、事实提取与事实更新记录，同时隐藏凭据和内部推理内容。
- 长篇写作按已确认事实、章节修订和剧情边界逐章推进，降低人物状态、时间线、证据边界与资源数量发生漂移的风险。

#### 修复

- 逐卷写作的一致性检查、事实提取和事实审核增加单次 5 分钟总时限；暂停或结束等待当前请求最多 15 秒，超时中止并保留续跑进度，步骤日志持续显示等待耗时。
- 修复暂停请求可能越过当前安全检查点、恢复后重复执行已完成准备步骤的问题。
- 修复事实审核引用非连续正文时任务无法自愈的问题；现在会保留正文和事实候选并自动重新审核。
- 修复保存响应丢失、人工修改正文或审核记录写入失败时可能重复生成或误覆盖的问题。
